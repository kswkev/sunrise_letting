Filter by rent and bedrooms

HTMX: form gets hx-get="/properties" hx-target="#search-results" hx-push-url="true". With HX-Request the server returns only the #search-results fragment, otherwise the full page. The rent and bedroom filters sit in a native <details> (works without JS). The server renders it open when any filter is set, as here; otherwise it is closed so mobile users reach the results quickly. Filter row above the list seen on Rightmove results and OpenRent results.
