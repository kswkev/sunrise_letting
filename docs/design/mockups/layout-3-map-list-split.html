Map placeholder. Pins are numbered to match the list.

Design note: the list is always complete and comes first in source order; the map is a supplement, hidden from assistive technology (aria-hidden="true") and not shown below 64em wide, so at 400% zoom only the list remains. "List" and "List and map" are plain links (?view=), so they work without JS. HTMX: the filter form swaps #search-results as in Layout 1; the fragment would carry pin positions in data- attributes for the map script to redraw after htmx:afterSwap. No "search as I move the map", because that only works with JS.
