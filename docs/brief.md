# Product brief: Property Letting Agent Site

## Purpose
Let Visitors search and view properties for let. With a separate area for Property Mamagers to run administration

## Users
- Visitor: browses and searches properties for let
- Property Mamagers: lists properties for let and manages existing tenancies

## Features (one line each)
- Visitor can sign up and log in
- Visitor can request a viewing
- Visitor can apply for a property
- Property Mamagers can log in
- Property Mamagers can edit existing property listing

## Constraints
- Runs on Kubernetes, one service per domain area
- All development will be driven from github issues

## Out of scope (for now)
- Acceptance of property applications and creation of leases
- Distinct user accounts for Landlord, Tennant, Property Assistant and Admin
- Termination of leases and readvertsing a property

## Open questions
- Layout for website
